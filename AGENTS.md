# Project operating instructions

Before making changes or answering infrastructure questions in this repository, read `docs/PROJECT_INVENTORY.md`.

Treat that file as the canonical technical inventory for the user's GitHub account, connected integrations, MCP configuration, Codespaces/Codex workstation, verified state, and outstanding work.

Rules:
- Keep the inventory current after every material infrastructure change.
- Distinguish ChatGPT connectors from MCP servers configured in Codex, repository MCP declarations, and actually running services.
- Never request or print secret values. Record secret names and locations only.
- Do not assume a component is deployed or running unless verified.
- Do not modify other repositories or trigger deployments, paid usage, or destructive operations without explicit approval.
- Prefer iPhone-first instructions and do not assume access to the user's home PC.
